# 🐍 Snake Game

## 🎮 Features

- Arrow-key controls
- Snake growth after eating food
- Score tracking
- Collision detection with walls and the snake’s body
- Game-over message

## 🕹️ Controls

| Key | Action |
|-----|--------|
| ↑ | Move up |
| ↓ | Move down |
| ← | Move left |
| → | Move right |

The snake moves automatically. Use the arrow keys to change its direction. Direct reverse turns are blocked.

## 🚀 How to Run

You need **Python 3** with Tk support, which Turtle uses to display the game window.

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

```bash
python main.py
```

Depending on your system, you may need to use `python3` instead of `python`.

## 🛠️ Built With

- Python 3
- Turtle — graphics and keyboard events
- Object-oriented programming
